# Documentation

This is the stable entry point for dated project records that support the maintained
playbooks, guidelines, references, and case studies.

| Area | Purpose |
| --- | --- |
| [Project records](project/README.md) | Research, specification lifecycles, flow documentation, and publication material |
| [Repository reviews](reviews/) | Dated engineering, maintenance, documentation, and supply-chain assessments |

Plans and reviews preserve decisions and implementation history. They are not the
primary source of current user guidance. Use the repository’s top-level
[`playbooks/`](../playbooks/), [`guidelines/`](../guidelines/), and
[`references/`](../references/) directories for maintained instructions.
