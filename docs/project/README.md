# Project Records

This directory contains durable project evidence and the lifecycle index for temporary
implementation plans.

| Area | Purpose |
| --- | --- |
| [Playbook flow overview](playbook-flow-overview.md) | Maintained map of the playbook’s phases, resources, and document relationships |
| [Research](research/) | Source-backed investigations, dependency inventories, and distribution studies |
| [Specifications](specs/README.md) | Stable index of active and completed implementation plans |
| [Publication source](posts/post-2026-03-04-rust-porting.md) | Long-form project article and its tracked assets |

Individual plan files are lifecycle records. When a plan is completed, move it from
`specs/active/` to `specs/done/` and update the specifications index in the same
change. Maintained guidance belongs in the repository’s top-level documentation
directories rather than in a completed plan.
